# Corroborate with dated spatial evidence

Read [investigation contract](references/investigation-contract.md). Use ROI geometry and actual clear-image acquisition dates to design evidence queries.

1. Determine country/jurisdiction from AOI coordinates. Search official national orthophoto archives, dated aerial imagery, road/construction/forestry records and topographic databases first. For an Estonian AOI verify current official national geoportal orthophoto and road sources; do not assume the AOI is Estonian because the user lives there. Check availability, licensing, historical dates and native resolution before access.
2. Seek clear before/after imagery with sufficient effective resolution for the measured width. Other Sentinel-2 dates test persistence but share a sensor/provider lineage; Landsat may be too coarse; commercial/high-resolution imagery may be restricted. Use only authorized access. Request minimum AOI windows with existing provider/cache abstractions, record access mode and local cache paths, and avoid full-scene downloads where unnecessary.
3. Obtain exact acquisition dates or documented mosaicking intervals. A current basemap, map copyright year or STAC publication time is not an observation date. An undated image cannot establish a construction interval. OSM full-history edits can identify a prior mapped feature; an edit timestamp is not a construction date and missing OSM data is weak negative evidence. Record original imagery lineage to avoid treating multiple maps derived from one image as independent confirmation.
4. Compare georeferenced crops side by side with a shared footprint. Account for registration, positional error, shadow/vegetation obscuration, resolution and seasonal visibility. Use a metric buffer reflecting measured uncertainty, not an arbitrary tight pixel match. Record each source as supports, contradicts, inconclusive, unavailable or inaccessible for each separate claim. A source cannot reject existence when the feature would be unresolved or obscured.
5. If a road is clearly absent in an adequately resolved unobscured before image and present in a dated after image, bound appearance between those acquisitions, explaining uncertainty. Prefer multiple dates. Distinguish construction from reopening/widening. Check contextual connectivity/width/surface, official records or field evidence for road identity. Verify prior forest separately with an approved dated baseline if forest claims are assessed.
6. Write corroborate/independent_map_evidence.json, corroborate/corroboration.md and dated georeferenced comparison crops under corroborate/crops/; make a supplementary offline Leaflet map under corroborate/maps/ where practical. Keep downloads in cache/. Retain source attribution/license, checksums, observation dates, query logs and source-independence groups. Update investigation.json and record explicit remaining evidence needed. Run the review site builder from the contract. Do not regard unresolved as rejected or supported.
